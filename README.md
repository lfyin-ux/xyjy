# 同行时空 · 校园社交平台

一个包含微信小程序、管理后台、后端服务和数据库的完整校园社交平台项目。

## 技术栈

- 后端：Spring Boot 2.7 + MyBatis Plus 3.5 + MySQL 8 + JDK 17
- 管理后台：Vue 3 + Vite + Element Plus + ECharts
- 小程序：微信原生小程序框架
- 数据库：MySQL 8

## 目录结构

```
xyjy/
├── backend/          后端 Spring Boot 项目
├── frontend/
│   ├── admin/        管理后台 Vue 项目
│   └── miniapp/      微信小程序项目
├── sql/              数据库脚本
│   ├── 01_schema.sql     建库建表脚本
│   ├── 02_mock_data.sql  演示数据脚本
│   └── run_sql.py        脚本执行工具（保证中文正确导入）
├── uploads/          用户上传文件本地存储目录
└── index.html        小程序设计稿
```

## 功能模块

### 用户端（小程序）
- 微信登录、双认证（个人认证 + 学校认证）与同校数据隔离
- 心动推荐、喜欢/跳过、双向匹配、我的匹配、谁喜欢我
- 校园广场：发布图文动态、点赞、评论、举报，内容分级审核
- 即时聊天：会话列表、打招呼准入规则、敏感词过滤
- 校园生活：校园跑腿、二手市场、游戏组局
- 校园商城：商品浏览、购物车、下单支付、我的订单、退款售后
- 个人中心：资料编辑、相册、访客、意见反馈

### 管理后台
- 管理员登录、角色权限
- 用户管理、资料审核、限制发言、封禁解封
- 个人认证与学校认证审核队列（身份证/证明材料查看、脱敏）
- 内容分级审核（动态、评论）、举报处理、命中记录
- 违规词库与审核词库管理
- 校园广场管理、跑腿订单管理、二手市场管理
- 商城商品与订单管理、发货、退款处理
- 数据统计仪表盘

## 内容分级审核规则

内容提交后先检测违规词，命中则直接拦截禁止发布；未命中再检测审核词，命中则转人工审核；都未命中则直接发布。同时命中两类词时以违规词规则优先。

## 运行步骤

### 1. 初始化数据库

数据库密码为 123456。由于路径含中文，推荐使用提供的 Python 脚本导入（需要 pymysql）：

```
cd sql
python run_sql.py 01_schema.sql
python run_sql.py 02_mock_data.sql xyjy
```

### 2. 启动后端

```
cd backend
mvn spring-boot:run
```

后端运行在 http://localhost:8080/api

### 3. 启动管理后台

```
cd frontend/admin
npm install
npm run dev
```

访问 http://localhost:5173 ，演示账号 admin / admin123

### 4. 运行小程序

用微信开发者工具打开 `frontend/miniapp` 目录。真机调试时请将 `app.js` 中的 `baseUrl` 改为电脑局域网 IP。

## 文件上传说明

所有图片/附件均为本地上传，保存在项目根目录 `uploads` 文件夹下，按业务类型和日期分目录，数据库中仅存储可访问的相对路径。
